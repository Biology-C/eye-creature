# 眼球怪 Eye Creature

**[🎮 立即線上試玩](https://biology-c.github.io/eye-creature/)**

[English](README_EN.md) · [原作 Mouse Maze](https://github.com/Biology-C/mousemaze)

獨立的像素風動作迷宮原型。扮演被魔王軍改造成生物兵器的勇者眼球，拍翼、滑翔並穿過「殘光培養所」，找到三顆引路光點逃出出口。

這是從 Mouse Maze 實驗區拆出的獨立遊戲；之後程式、素材、議題與版本均在本 repository 維護。Mouse Maze 的原始冒險、教育與機關迷宮模式繼續留在原專案。

## 目前可玩內容

- 第一關：多岔路迷宮、探索火炬、小地圖、休息燈及針刺。
- 水晶老鼠跳撲，受傷變成史萊姆；青影鳥、樹妖與鏡面技能。
- 三段近戰連招／遠距蓄力光彈、衝刺、命中與受傷特效。
- 藍色翼能碎片，每累積 100% 回復半心；橘色能量 30 點可破壞指定裂牆、天花板或地板；三件支路藏品。
- 鍵盤與觸控、深淺色、減少動態。

## 開始遊玩

安裝 Node.js 22 以上，在本資料夾執行：

```sh
npm start
```

開啟 http://127.0.0.1:8768/ 。遊戲是靜態 HTML/CSS/JavaScript，不需建置；啟動伺服器不需安裝 npm 相依套件。也可用其他靜態 HTTP 伺服器，請勿直接雙擊 HTML。

| 操作 | 按鍵 |
|---|---|
| 移動 | ← →／A D |
| 拍翼；耗盡後滑翔 | ↑／W |
| 下降、穿過薄台 | ↓／S |
| 近敵連按接三段近戰；遠處短按光彈、長按蓄力後放開 | Space／觸控攻擊 |
| 衝刺 | Shift |
| 鏡面 | Q |
| 破裂面 | E；上下裂面搭配 ↑／↓ |
| 預留切換魔法 | F，目前只有光彈 |
| 暫停 | P／畫面按鈕 |

**尚無跨重載存檔。** 死亡保留本局收集與探索狀態；重新整理或重新開始會重置。本機舊分頁的進度不能搬到新網址。10–15 分鐘是設計目標，實測可能更長；後續關卡與多種魔法仍未實作。紅熊是第一版程式繪製造型，待試玩確認。

## 開發與測試

```sh
npm ci
npx playwright install chromium
npm test
```

測試會自行啟動臨時 HTTP 伺服器，包含模型測試、鍵盤／手機 UI 與三光點至魔王入口的路線可達性檢查（隔離傷害），另有魔王戰與死亡測試。產物位於忽略的 `tests/artifacts/`。可用 `BROWSER_CHANNEL=chrome` 環境變數改用已安裝 Chrome。正式遊戲不依賴 Playwright。

## 本機試玩更新：紅熊與三款斬擊

- [並排比較斬擊](previews/combat/index.html)：銀白細刃、暗影爪痕、赤金重斬；遊戲上方按鈕也可切換，傷害範圍一致。
- 收齊三光點後由原出口進入守門室，紅熊 30 HP；近戰或光彈每次命中 1 點。擊敗後走向右側門通關。
- 紅熊預告揮爪，每第三轮施放認知顛倒：玩家外觀變史萊姆、紅熊外觀變眼球怪，控制與碰撞不變。Q 或左側固定鏡子解除。死亡後重試魔王，生命恢復 30；迷宮收集保留。
- `/?boss-preview=1` 直接試玩守門室，明確標示紅熊試玩，不代表完成迷宮。
- 樹妖改為 5 HP；青影鳥每區最多 5 隻，原本 18 秒增援節奏不變。

## 藏品能力與敵人更新

三件藏品現在各有固定能力，拾取立即解鎖、可同時持有，死亡保留，新局重置：

| 藏品 | 能力 |
|---|---|
| 稜光徽章 | 遠距一次發射三顆扇形光彈；每顆 1 傷害，同一輪不重複傷害同一敵人 |
| 疾風緞帶 | 衝刺造成 1 傷害，每敵每次衝刺最多一次；冷卻由 1.2 秒降至 0.6 秒，仍非無敵，不能砍樹 |
| 破界劍柄 | E 可破壞普通內牆，仍消耗 30 點能量；上下搭配方向鍵，保護外框與魔王房 |

地板尖刺擴充為對稱天花板與錯落牆面配置，沿用 3 秒收起／3 秒伸出與提前警示；部分錯開半個週期。破牆拆掉支撐面後尖刺失效。

樹妖保留 5 HP，附近玩家進入視線後會蓄力 0.8 秒施放綠色龍捲風；反彈兩次，第三次撞牆或 7 秒後消散，碰到玩家扣一心並消散。施法間隔 3.5 秒，死亡重試清除飛行龍捲風。史萊姆會預告後跳躍，高度與速度設定見下方更新。

## 純史萊姆與石磚更新

- 按固定種子在合適房間隨機配置純史萊姆；目前種子生成 20 隻，避開起點、出口、光點、休息燈與尖刺房間。一次命中擊敗，不隨時間增生，死亡不重生。
- 所有史萊姆（含水晶老鼠受傷轉化）最高跳躍高度為老鼠約兩倍；地面／爬行速度 42.5px/s、空中水平速度 206.25px/s，皆為老鼠對應速度的 1.25 倍。跳躍初速以平方根二倍計算，避免將兩倍高度誤作四倍。
- 可貼牆上爬、沿天花板倒掛移動並轉角；精靈隨表面轉向。支撐面被破壞後掉落，仍受碰撞與受擊停頓限制。
- 地形重繪為原創程式生成的冷灰石磚、灰紫石磚與苔色石磚，包含接縫、邊緣高光、底部陰影、裂痕及苔痕；參考提供圖片的材質方向，未直接截取其中素材。地圖碰撞形狀不變。

## 密度、紫色大史萊姆與五格生命（V1.15）

- 尖刺最大長度 30 → 37.5px（像素繪製約 38px）；移除尖刺前方 64px 區域內重疊的薄平台片段，避免站在線段上躲過針刺。
- 普通純史萊姆固定隨機配置 20 隻；索敵水平／垂直距離提高至 162.5／100px，反應蓄力約 0.52 秒，移動速度維持老鼠的 1.25 倍。
- 青影鳥初始 20 隻、分布在 20 區。畫面內出現且視線不被牆阻擋時啟動該區增殖，此後每 1.5 秒一隻，每區同時最多 6 隻；離開畫面仍持續，清光該區停止。不是全地圖 6 隻。
- 紫色大史萊姆 5 隻，首輪設定 3 HP；速度為一般史萊姆 0.75 倍，接觸扣 2 格生命。死亡分裂 4 隻綠色小史萊姆，只分裂一次；本局死亡不復活已死的大史萊姆，子體保留。
- 玩家上限 5 格，使用像素愛心＋五段 HP 血條，可顯示半格。回血、休息燈、死亡及魔王房補血均遵循同一上限。
- 生命大於零且 ≤1 格時，畫面四周紅光呈 1.2 秒一輪雙拍心跳；回血超過 1 格立即消失。減少動態改為固定紅邊；暫停凍結脈動，不加入聲音。

測試區分路線可達性（隔離傷害的導航測試）與戰鬥／死亡測試。高密度下實際玩家生存難度尚待試玩，不以自動走路結果當成難度驗收。

### 連段與蓄力試玩

Space／觸控攻擊：近敵連按依序直斬、迴旋斬、前衝十字斬；接招間隔 0.32 秒、窗口 0.85 秒，可預輸入後兩招。每招對同一敵人只造成一次傷害，牆會阻擋攻擊與前衝。遠處短按放開發射光彈，冷卻 0.5 秒；長按 0.8 秒再放開，發射單顆大型光彈，傷害 1.5 倍。三向藏品仍作用於普通光彈。暫停、失焦或死亡取消蓄力及排隊接招。綠色龍捲風使用橫向密集旋繞風團，維持反彈兩次規則。
