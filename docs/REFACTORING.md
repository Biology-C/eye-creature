# 重構安全網與平衡設定

## 行為基線

Golden 在搬移數值前錄製，遊戲基準為 ce4a9a2；測試與初始 golden 保存在 2be2381。
使用探索版固定種子 2917、1280×720 桌面視窗、每次 1/60 秒的虛擬時鐘及固定亂數序列。
所有頁面使用獨立瀏覽器 context，測試不碰使用者平常試玩的儲存資料。

輸入序列位於 tests/helpers/replay.cjs，以 `{ step, action, down }` 表示哪個模擬步按下或放開。
action 經真實 keydown／keyup 事件進入遊戲，沒有傳送玩家、直接扣血、關閉敵人或加無敵。
requestAnimationFrame、performance.now 與 Date.now 由測試時鐘接管；保留真正的 loop、hitStop、
物理、碰撞、敵人與渲染。step 是固定時鐘的更新機會，hitStop 時世界時間照既有规则暫停，
因此 1200 步等於 20 秒輸入時間，遊戲內 time 可能略少。

| 腳本 | 長度 | 覆蓋情境 |
|---|---|---|
| opening | 480 步 | 起點往右、42 能量、發現裂牆、E 破牆、風道開啟 |
| exploration | 1020 步 | 延續開場路線，包含拾取、敵人接觸受傷及攻擊擊倒 |
| boss | 1200 步 | boss-preview 入口、移動、蓄力／近戰、衝刺、援軍、變身、受傷與死亡重設 |

每 30 步（另含起點）保存玩家取整位置、HP、能量、光點、擊倒數、活敵數、紅熊 HP、
遊戲時間，以及敵人位置／HP／狀態、已破牆、拾取數、死亡數與詛咒狀態。
tests/golden/*.json 同時附輸入序列，方便審查，不是每次測試重算的「預期值」。
測試報告第一個不一致的 step、欄位路徑、預期與實際值；例如 samples.8.hp。

## 執行與更新

```sh
npm run test:unit
npm run test:browser
npm test
```

三段回放隨 test:browser 與 test 一起執行。npm test 自行建立臨時靜態伺服器。
首次安裝需 npm ci 及 npx playwright install chromium；已有 Chrome 可用 BROWSER_CHANNEL=chrome。

只有任務明確要求改變行為時，才可執行：

```sh
npm run replay:update
```

此指令啟動臨時伺服器並覆寫三份 golden。**一般重構禁止執行更新**；不一致時先找程式問題，
不得以重新錄製讓測試變綠。刻意改行為時須審查 JSON 差異、記錄理由並提交新基線。
初次建立安全網的錄製是唯一初始化例外，本次數值搬移後沒有更新 golden。

## 平衡數值

src/config/balance.mjs 是單一入口；所有現值與搬移前相同，沒有調強、調弱或重設冷卻。
區分 player、attack、enemy、population、candidates、legacy、boss、recovery、energy、wind、
spikes、guidance。單位預設為秒、px、HP；例如斬擊傷害陣列對應第一至第三段。
保留原算式（如史萊姆跳躍 -250 × √2），不以近似小數取代。

DEFAULT_BALANCE 是深層凍結快照；BALANCE 為本頁模組實例，僅 debug 白名單功能會暫時修改。
一般平衡調整修改檔案後重新載入；數量採候選池與保留量分開，避免只搬常數就改變地圖選點。
視覺曲線、精靈尺寸、固定關卡座標、碰撞取樣等不在本次平衡搬移範圍。

## 除錯面板

本機 http://127.0.0.1:8768/?debug=1；直接測魔王可用 ?boss-preview=1&debug=1。
只有精確的 debug=1 會動態載入，debug=0 或一般網址不顯示、不載入除錯模組。

- 可調紅熊 HP、傷害、預告、速度，以及各敵人 HP、速度、索敵、青影鳥增殖設定。
- HP 按比例套用目前存活敵人；不讓死敵復活。計時設定在下一輪使用，移動與索敵立即读取。
- 玩家無敵、跳魔王房、補滿 HP 與至少 300 能量；能量原本沒有上限，300 是測試補給額度。
- FPS 以最近約 0.5 秒實際渲染幀估計，不改變世界步長；編輯欄位會清除遊戲按鍵以免卡鍵。
- 還原按鈕只還原設定與無敵，不重建關卡；重新整理重設所有臨時值與此次測試進度。
- 整個 debug 頁不讀取、寫入或刪除旅程存檔，休息燈也不保存；原存檔保留。
  聲音音量等偏好仍沿用原有機制。關閉 debug 網址後才回到正常存檔流程。

## 驗收與限制

除了三段 golden，新增設定路徑有效性與除錯瀏覽器測試，涵蓋非法輸入、即時數值、
無敵、補給、魔王跳轉、FPS、還原、重載與存檔隔離。
一般模式另比較與重構前相同的 8 張固定狀態 PNG，覆蓋桌面與手機的開場、裂牆、牆刺與紅熊。
這些測試不代表每一條路線、所有長時間輸入或真人手感均已涵蓋；音效聽感未人工重聽。
本次不推送，線上版本不受影響。
