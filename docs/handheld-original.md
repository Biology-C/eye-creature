# 原版手機掌機介面

更新日期：2026-09-29。移植探索改造版核定的綠灰像素掌機布局，僅套用於觸控裝置（`pointer: coarse`），開發預覽可加 `?handheld=1`。

## 保留原版

原版迷宮生成、敵人數量、傷害、三段斬位移、藏品與魔王規則不更換；不匯入探索改造版的主線、風道、殘響或 localStorage 存檔。桌面 HTML 控制與 E/Q/Shift 鍵位保留。手機操作面板於啟動時組裝，桌面不重排。

## 手機操作

- 十字鍵左右移動、上下觀察（下可下降），B 拍翼／滑翔，A 攻擊／蓄力，X 衝刺。
- 近戰目標及連段優先；面向可破牆且有 30 能量時，長按 A 0.65 秒拆牆。短按發普通攻擊，成功才扣款，一次長按只拆一面。
- 破牆鎖定初始牆 ID，轉向／離開範圍、受傷、敵人進入近戰或暫停／失焦／觸控取消均會中止。
- 原版側裂牆下緣高於落腳點：手機以完整牆面加上下 32px 瞄準容許範圍維持鎖定，避免自然落地取消；水平距離仍為 56px。桌面 E 鍵的判定不變。
- 移除手機鏡面按鍵，20 個青影鳥區域各放置場景鏡面。靠近 40px 且有可映照目標時觸發，維持原本 180px 作用範圍、遮擋與 6 秒冷卻。本機第二版改由魔王重踏掉落鏡子破解認知顛倒；變身期間 A 跳撞、B 跳躍／攀附、X 停用。詳見 bear-metamorphosis-v2.md。
- SELECT 暫停並查看已探索地圖；START 暫停／繼續。深淺色、減少動態、斬擊樣式、能力及藏品資料放入手機暫停面板，可由面板感應方向並繼續遊玩。

## 驗證

- 本機完整 28 個測試檔通過，含既有桌面戰鬥、魔王、破牆、藏品及死亡回歸。
- 390×844、844×390、360×740、740×360 的觸控瀏覽器模擬：無頁面捲動，核心按鍵至少 56px 且在畫面內。
- CDP 三指操作、單指釋放、取消、暫停清除、地圖、短按／長按、四向破牆、能量不足與敵人優先、蓄力魔法均通過。
- 100 個原版種子都有 20 處地面鏡面，避開尖刺；加入物件前後地圖陣列完全相同。場景青影鳥反射與魔王詛咒解除通過。
- 真實 iPhone Safari／Android 裝置的瀏覽器工具列、拇指觸感與操作疲勞仍需實機試玩；模擬通過不代表實機驗收。
