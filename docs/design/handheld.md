# 手機掌機介面 — 2026-09-29

## 範圍與辨識

探索改造分支專用。主要指標為粗略觸控（`pointer: coarse`）；桌面維持原有介面與 Space/E/Q/Shift。開發預覽可加 `?handheld=1`，`?legacy=1` 不套用新版介面。原版 main 遊戲不修改。

介面採綠底黑像素 HUD、灰階機身、CSS 像素按鍵；Canvas 遊戲維持彩色。直向畫面在上、控制在下，橫向控制移到左右。使用 100dvh 與安全邊界；核心方向鍵至少 56×56，A/B/X 至少 60×60。SELECT/START 為 44px 高系統鍵。

## 操作與判定

- 十字鍵：左右移動、上觀察、下觀察／下降；B 拍翼與滑翔，獨立於向上觀察。
- A：同一來源的近戰／魔法判定。有效近戰或連段優先；否则面向可破牆且持有至少 30 能量，可鎖定牆 ID 並蓄力 0.65 秒破壞一次。無符合條件的牆時沿用 0.8 秒蓄力魔法。
- 破牆前短按仍發普通光彈，不扣破牆能量。完成才扣 30；長按不連拆。移開、轉向、受傷、敵人進入近戰、暫停／失焦或取消觸控會取消。一次按下後不改鎖另一面牆。
- X 保留衝刺及既有藏品傷害與冷卻，按鍵顯示剩餘冷卻。
- 手機隱藏獨立鏡面按鍵；6 處青影鳥／樹妖區域新增原創鏡面物件，玩家靠近 40px 且有可映照青影鳥時觸發，射線及 180px 作用範圍、6 秒冷卻沿用既有鏡面。紅熊房原有鏡子仍可解除詛咒。新增物件僅手機渲染及作用，不改桌面關卡或存檔格式。
- SELECT 暫停並顯示已探索地圖；START 暫停／繼續。暫停清除觸控持有狀態。

`src/handheld.mjs` 提供判定、指標 ID 管理與場景鏡面；`styles/handheld.css` 僅作用於 `.handheld`。手機操作按鍵使用 Pointer Events，放開一根手指不取消其他手指。
