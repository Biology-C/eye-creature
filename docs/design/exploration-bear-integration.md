## 音效接點

| 名稱 | 接點與限制 |
|---|---|
| hit | enemyDamageSound → combatSounds.damaged；近戰、光彈、衝刺、applySlimeHit跳撞、鏡像自傷。loop尾端合併同幀，間隔至少40ms；非致命紅熊使用big音色 |
| hurt | hurt實際扣血、仍存活才播放；無敵時不播 |
| defeat | 扣血觀察器：一般敵人歸零；水晶老鼠初次跨入史萊姆HP使用transform；大史萊姆本體一次 |
| bossWarn | updateBoss前後ready狀態邊界，每次一秒攻擊預告開始一次 |
| orb | update光點拾取，取代當幀普通pickup |
| mirror | mirror的Q成功映照(count>0)、手機場景鏡count>0、updateBoss.cured拾鏡回呼；空目標／冷卻／Q不能解詛咒均不播 |
| curse | syncForm裡setSlimeForm成功且新形態為true，僅轉換時一次，同時取消蓄力聲 |
| bossSummon | updateBoss.summon回呼標記，該次update結束只播一次；同次跨多門檻不疊播 |
| bossDefeat | combatSounds.damaged觀察紅熊HP正值變0；取代一般defeat並抑制該幀待播hit，所有四種傷害路徑共用 |
| death | hurt實際扣至0，取代hurt；不因復活清理再播 |
| levelClear | update首次轉won顯示通關面板；音效可播放時music.duck(1500)，不更動玩家設定或localStorage |

music.duck將輸出gain乘0.5，1.5秒後回到當下設定音量；期間調音量、靜音、切換曲目均保留正確狀態，新冒險清除尚未結束的降音量。所有新增音訊仍使用原本使用者操作後建立的AudioContext；音訊失敗不阻止遊玩。音效預設40%、背景音樂20%。
