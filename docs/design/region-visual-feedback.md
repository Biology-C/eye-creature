# 區域識別、敵人密度與視覺回饋

日期：2026-10-08。工作分支：`feature/first-adventure-rework`。當日本機交付；2026-10-09 經使用者確認，與後續能量調整一起發布。

## 決定與範圍

- 依先前「一起調整」要求實作區域氣流、牆刺、裝飾與敵人減量；這些是先前已指定的玩法調整。
- 最新美術回饋優先：**保留進守門室補滿生命**，未滿才顯示回血效果與「守門室前：生命已回滿」。不是取消補血。
- 視覺部分不更動生命上限、補血量、攻擊傷害、冷卻、敵人個體血量、紅熊招式或鏡頭。小怪維持既有受擊顯示。

## 區域

既有 `terrain.mjs` 的區域配色已符合苔色／灰紫／冷灰要求，保留原調色與碰撞。`region-features.mjs` 以固定房間資料安裝：

| 區域 | 小物件 | 裝置與安全性 |
|---|---|---|
| 培養室 | 低對比小培養瓶 | 原有配置 |
| 根脈庫房 | 垂落藤蔓 | 房間45與64各一組128px橫向氣流；保留完整地面，出口不設坑洞；与初始敵人、尖刺至少120px |
| 裂鏡走廊 | 灰紫蘑菇 | 房間94與114各一處牆刺；保留中央平台作等待位置 |
| 廢棄觀測室 | 冷色奇異花叢 | 原有配置 |

氣流以遊戲時間計算：吹5秒／停2秒，6.5秒起預告、7秒重啟；白色直線與發光格柵、一次短音提示，減少動態改固定箭頭。只有玩家受推力，漂移650px/s²、上限150px/s；原本260px/s行走速度不變，所以可逆風前進。離開風帶或停風解除漂移，不影響敌人、魔法、翼能或傷害。裝置不挖牆、不挪平台。

初始敵人改為老鼠8、純史萊姆7、大史萊姆2、樹妖3、青影鳥4；保留主路、刪除支路及重複遭遇優先。青影鳥以**整個主題區共用**3秒計時、存活上限4；離區暫停、清空停止，樹妖召喚也受區域上限限制。手機原有六面場景鏡保留，位置獨立於初始青影鳥數量。

配置版號升為 `adventure-3`，避免舊敵人快照恢復出舊密度。舊存檔不刪除，依既有相容性介面提示，開始新冒險仍需確認覆蓋。

## 共用回血與紅熊呈現

- `feedback.mjs` 的 `createHealingFeedback` 由 `updateHud()` 觀察生命增加，包含碎片滿100%、首次點燈、危急能量、守門室與死亡返回回血；重設／讀檔同步基準，不將載入數值誤報為治療。
- 綠色上升粒子與`+N`維持0.6秒，HP條只標示真正恢復的完整或半格，維持0.4秒。滿血沒有新特效，減少動態只保留HP標記及不移動的浮字。計時以遊戲時間凍結。
- `beginBoss()` 未滿血時顯示補滿提示；合併守門室標題，避免下一幀區域名稱覆蓋提示。
- 偽裝眼球的 `wingFrame()` 使用主角每秒8格／6格循環；淡紅輪廓辨識，減少動態採靜止影格與紅外框。
- `enemyDamageSound()` 是近戰、光彈、衝刺與史萊姆跳撞的共用實際扣血回報，呼叫 `markBossHit()`；只有紅熊更新染色時間，受擊不改傷害／硬直。
- `createBossPainter()` 保留原圖透明度輪廓，覆蓋近白亮紅`#ffe0e3`，從命中起1秒線性退回原色，重複命中重新計時。原形及偽裝共用；預告線、血條與其他怪物不染色。
