音量預設為 20％，可選 100％、75％、50％、20％、10％、0％（靜音），以 Web Audio GainNode 控制；不改變使用者裝置音量。三首循環播放，單一串流播放器避免換場疊音。同曲暫停後繼續原進度，換場從新曲開頭播放。錄音本身的頭尾保持原檔，沒有額外剪輯。

標題按音樂按鈕啟用標題曲，也可直接開始／續玩啟用場景曲。背景音樂和原有音效分別控制；音量與靜音狀態保存在目前瀏覽器；無設定時預設 20％，儲存失敗則維持本次遊玩設定。暫停、失焦、隱藏分頁停止音樂；遊戲暫停後必須明確繼續。音訊無法播放時顯示重試，不阻擋遊戲。音樂不加入休息燈存檔。

測試：`eye-music.test.mjs` 驗證 0.20 預設增益與六段音量、場景選擇、靜音、暫停續播、不自動播放及錯誤重試；`eye-music-browser.test.cjs` 驗證三首實際 MP3 解碼播放、標題／探索／魔王／死亡／通關切換、背景暫停、單播放器、手機橫直向控制及子路徑載入。音量的主觀舒適度與真實手機喇叭仍需玩家確認。

2026-09-30：本機 Chrome 完成全部 32 個測試檔，全部通過；三首音檔 SHA-256 與使用者原檔一致。此次交付為本機探索版，未發布至 GitHub Pages。
