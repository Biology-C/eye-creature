# 探索版電腦鏡頭舒適度調整（2026-09-30）

玩家回饋左右轉向晃動太強。本次僅調整探索版桌面鏡頭；角色移動、垂直跟隨及手機鏡頭維持既有規則。

| 設定 | 原設定 | 本次 |
|---|---|---|
| 左右前視 | 畫面寬度 12% | 6% |
| 前視轉向等待 | 面向改變後 200ms，鬆鍵仍會觸發 | 方向鍵持續按住 250ms，鬆鍵取消計時 |
| 水平平滑跟隨 | 指數係數 8/s | 4/s（反應時間約兩倍） |
| 水平緩衝 | 無 | 目標位置左右各 4% 畫寬 |

位置跟隨仍持續進行，延遲只作用於前視方向；角色操作沒有輸入延遲。衝刺保留畫面邊緣 40px 的安全跟隨，復活／讀檔／換場立即定位。緩衝区減少反覆調整站位時的掃動。

驗證：30／60／120 FPS 的短按後鬆鍵、持續轉向、衝刺與復活測試通過。960px 寬、固定角色位置左右轉向各等待 3 秒的控制測試，鏡頭位移由約 230.4px 降至 38.4px（包含新增緩衝效果）；這不代表正常行進時跟隨距離也削減相同比例。100 個支路種子與完整探索路線瀏覽器回歸通過。實際舒適度仍需玩家試玩確認。
