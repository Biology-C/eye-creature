# 殘光培養所：玩家說明

狀態：**現行規格**。工程位置與數值基準見 [現行規格快照](current-game-spec.md) 與 [模組導覽](../ARCHITECTURE.md)。

你曾是勇者。現在，你的眼睛被改造成有翅膀的生物兵器。找到三顆引路光點，擊敗守門紅熊，親手打開逃出去的路。

支援桌面鍵盤與手機掌機介面；實機手機的手感與聲音仍待試玩確認。

開場只保留身世、目標與基本移動。完整操作可在暫停選單展開「操作說明」。同一教學只出現一次，成功操作後也視為學會；一般教學之間至少留15秒安靜時間，過時情境不會排隊補播。碎片、受傷與成功存檔不再彈文字，改由特效、音效、HUD數字與短暫存檔圖示回饋；存檔失敗仍會明確通知。

| 想做什麼 | 操作 |
|---|---|
| 左右移動 | ← → 或 A D |
| 拍翼、滑翔 | 按住 ↑ 或 W，落腳恢復翼能 |
| 下降、穿過薄台、抗風 | ↓ 或 S |
| 近戰連招 | 近處有敵人或障礙時，連按 Space |
| 普通光彈／蓄力光彈 | 遠處短按放開／按住0.8秒放開 |
| 衝刺 | Shift |
| 鏡面 | Q，讓青影鳥攻擊倒影；紅熊詛咒需拾取重踏掉落的鏡子 |
| 破牆 | E，消耗30能量；地板／天花板搭配 ↓／↑ |
| 暫停與設定 | P |

戰鬥、蓄力、拾取及衝刺音效為 Web Audio 原創程式合成，不含音檔；破牆另使用提供的「拆牆音效.wav」。桌面按 P、手機按 START，在暫停面板「背景音樂音量」旁調整「音效音量」（關／20%／40%／60%／80%／100%，預設40%）；音效開關同時控制戰鬥與發現、破牆、存檔提示音。兩種音量分別記在目前瀏覽器，儲存被封鎖時仍可使用本次設定。[合成音效試聽與 WAV 匯出](../../previews/sfx/)可單獨比較。

**觀察牆上的風聲。** 靠近可疑牆並面向它，眼球會逐漸發現裂紋。打破風口後，上升氣流可帶你到高處；下方仍可重試，不需重新收集已消耗的開門能量。

靠近裂牆且能量足夠時，只在第一次顯示「按E打破」（手機「長按A打破」）；之後牆旁保留小型按鍵圖示，地板與天花板附↓／↑，不再反覆跳大字。能量不足時不主動提醒，實際嘗試破牆才說明還差多少。第一面裂牆的教學會合併「能量已足夠」與破牆按鍵：距離120px內且有30點能量時立即出現，優先於一般提示；不會在路上先跳一次能量提示。按「感應方向」才會出現引導；手機可從暫停選單使用。各主題區首次進入只顯示名稱，不暫停遊戲。

**連招也能開路。** 直斬割細根、第二段迴旋斬清纏枝、第三段十字斬打薄障礙。按住前進時第三段位移較長；不按時位移減半。石牆仍需E破牆。

**能力與記憶卡片。** 取得藏品或勇者殘響時，中央會顯示大卡片，遊戲暫停，方便閱讀。顯示滿0.6秒後，按Space、Enter、手機A或點擊卡片繼續；這次操作不會出招。藏品卡片附上能力效果和對應按鍵。戰鬥中收集的殘響會等安全時再顯示，之後仍可在暫停選單「旅程與回憶」回看。一般碎片以圖像與音效回饋，不另彈文字；必要操作提示仍使用小提示。

**休息燈保存旅程。** 第一次點亮補滿生命，再次靠近只保存、不補血。死亡保留這次遊玩的收集、破牆與擊敗敵人；重新整理則回到最近一次燈的保存狀態。關閉後回來選「繼續冒險」。不同瀏覽器、本機和線上網址不共用存檔。

**紅熊守門室。** 收齊三顆光點後，從探索出口進入。紅熊有36生命，會揮爪、吐息與重踏，在剩餘75%、50%、20%生命時各召喚一波援軍。認知顛倒會真正把你變成史萊姆：↑跳躍／攀附，Space跳撞，暫時不能飛行、施法、衝刺或破牆。等重踏落下鏡子，再走近拾取恢復。擊敗紅熊前門保持關閉，可離開門邊，不必卡在門上；擊敗後走到門前通關。魔王戰死亡會重設紅熊和援軍，保留探索進度。

滿蓄力需按住0.8秒，放開後造成3點傷害；上一發冷卻時也能開始下一次蓄力。新增音效提示命中、受傷、擊敗／變身、魔王預告、光點、鏡面、詛咒、召喚、紅熊倒下、死亡與通關。通關旋律播放時背景音樂暫降一半，約1.5秒後恢復設定音量；靜音狀態不受影響。

**危急回復能量。** 紅熊重踏時，若你只剩2格生命以下、場上沒有大塊綠色能量，而且距上次掉落超過20秒，必定在遠離重踏的地面掉落一塊；首次符合條件即可掉落。拾取回復1格生命，最多5格。能量不會逾時消失，但死亡、重試或擊敗紅熊時清除。它有較大的綠色外觀和光暈；減少動態時光暈保持固定。

時間和難度仍在試玩調整中。若不知道往哪裡，使用「感應方向」，並觀察點亮的火炬與地圖上的捷徑標記。


## 手機掌機操作更新

手機自動顯示綠底灰階掌機介面，遊戲畫面仍為彩色。十字鍵左右移動、上下觀察（下可下降），B 拍翼／滑翔、A 攻擊／蓄力、X 衝刺。面向裂牆且有 30 能量時，長按 A 0.65 秒可破牆；過程中可放開取消，短按不扣能量。附近有近戰目標優先戰鬥。場景鏡面取代手機鏡面按鍵，靠近可映照青影鳥。變成史萊姆後B改為跳躍／攀附、A改為跳撞，拾取紅熊重踏掉落的鏡子解除詛咒。SELECT 地圖、START 暫停。桌面鍵位不變。

## 區域與回血辨識

根脈庫房是苔色磚與垂落藤蔓，白色直線氣流不造成傷害：吹5秒、停2秒，停風結束前半秒會亮起格柵，逆風仍能行走。裂鏡走廊是灰紫磚與蘑菇，兩處牆刺旁可在中央平台等待收起。觀測室是冷灰磚與奇異花叢。這些小物件只作裝飾。

實際回復生命時，會冒出綠色粒子與「+N」，HP條只亮起恢復的部分；減少動態不顯示粒子。進守門室依舊補滿生命，原本未滿時會提示「守門室前：生命已回滿」。紅熊偽裝的眼球仍拍翼，以淡紅輪廓辨識；打中後泛亮紅並逐漸回復。

## 能量與戰鬥調整

前輪橘色破牆能量提高60%（110→176點）；本輪開場另增3包各4點，總量188點、牆前42點。起點到第一面牆沒有主動攻擊敵人，水晶老鼠與蓄力教學移至破牆後。第二、第三件藏品附近及中後段回程的能量維持前輪配置，鼓勵取得能力後繼續開路；沒有額外的拾取條件。一般回血／翼能碎片與魔王危急回復能量統一為綠色，恢復量與觸發條件不變。

滿蓄力光彈造成3傷害，一發即可直接擊倒水晶老鼠；普通光彈仍需兩次命中，先變史萊姆再消失。三向藏品只影響普通彈。紅熊36HP，在27／18／7.2HP觸發三次召喚；12發滿蓄力直接命中紅熊可擊敗。斬擊範圍、衝刺傷害及危急回復規則不變。
