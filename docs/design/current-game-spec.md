# 探索版現行規格快照

狀態：**現行規格**。本文件整理實際實作，沒有提出新的玩法修改。
玩法基準是探索分支 f317d90；refactor/maintainability 整理排版、工具與文件，並將相同數值
移至 src/config/balance.mjs，加入回放安全網與僅 debug=1 可用的除錯工具。一般遊玩行為不變。
程式位置見 [ARCHITECTURE](../ARCHITECTURE.md)；玩家操作見 [玩家說明](adventure-player-guide.md)。
舊提案、逐次修改紀錄與美術提示詞統一保留為歷史資料，勿照其中舊數值覆蓋程式。

## 關卡與開場

- 關卡版本 adventure-5，預設種子 2917，32px 地磚；固定主線搭配六條種子支路。
- 找齊三顆引路光點才可進紅熊房；外框、必要門與魔王邊界不可任意破壞。
- 起點到第一面牆的教學地面路線不放主動攻擊敵人；原起點老鼠移到牆後。
- 第一面牆前共 42 點橘色破牆能量：30 個單點加 3 包各 4 點；每次破牆消耗 30。
- 全圖目前有 77 個橘色能量拾取物、合計 188 點，包含中後段能力取得後的額外資源。
- 第一次接近裂牆 120px 且能量足夠，立即顯示關鍵破牆教學，合併能量足夠提示。
  此提示不受一般 15 秒安靜間隔限制；第一次破牆前不先教無關的蓄力。
- 一般教學只出現一次，之後改用牆旁按鍵標記；碎片、受傷與成功存檔不反覆彈文字。
- 區域第一次進入顯示名称，守門室標題避開紅熊血條；玩家可主動使用感應方向。

## 紅熊、回復與視覺

紅熊維持揮爪、吐息、重踏及認知顛倒；詛咒真的把玩家變為能跳撞與攀附的史萊姆。
重踏時落下鏡子供解除，擊倒前出口門不開啟。魔王重試回復 boss.maxHp，不寫死 30。

危急回復在 HP ≤ 2、場上沒有能量、距上次掉落超過 20 秒的重踏時必定出現；
首次符合條件即可掉落，沒有隨機機率。大塊綠色能量回復 1 格，不逾時消失，
避開重踏／魔王與詛咒鏡子至少 120px，死亡、重試或擊敗魔王時清除。
進魔王房補滿生命是現行行為；原本未滿時顯示回滿提示及綠色回血特效。

一般回血累積能量亦為綠色；累積滿 100% 回復半格。
實際回血顯示綠色上升粒子約 0.6 秒、HP 回復部分閃綠 0.4 秒及 +N；減少動態時省略粒子。
紅熊偽裝為眼球時繼續拍翼並帶紅色辨識；受擊泛近白亮紅，1 秒線性回復，連續命中重設。

## 訊息、存檔與音訊

- 藏品與殘響使用中央大卡片並暫停世界；滿 0.6 秒後才可關閉，不把關閉輸入當攻擊。
  戰鬥中殘響延後到安全時顯示，暫停選單可回看。
- 休息燈首次補血，之後只存檔；死亡保留本局進度，重載回到最近燈的快照。
  存檔格式版本 1；關卡版本不相容時保留舊資料並說明原因。
- BGM 預設 20%，選項為 100／75／50／20／10／0%；SFX 預設 40%，每 20% 一級。
  localStorage 與音訊例外不阻擋遊戲；首次使用者互動後才能建立音訊環境。
- 音效為 Web Audio 原創程式合成，破牆另有提供的 WAV；BGM 使用三首提供的 MP3。
  音樂與音效來源以根目錄 ASSET_SOURCES.md 為準。
- 桌面鍵位與手機掌機都保留；手機 A 攻擊／蓄力、長按 0.65 秒破牆、B 拍翼、X 衝刺、
  SELECT 地圖、START 暫停，鏡面使用場景物件。

## 尚未由自動測試證明的目標

首玩 10～15 分鐘仍是試玩校準目標；通路可達與自動測試通過不代表真人手感、
音訊聽感或實機手機多指操作已驗收。歷史階段文件內的勾選只代表當時紀錄。
