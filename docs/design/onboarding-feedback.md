# 真人試玩回饋：安靜探索

2026-10-02，探索改造分支。2026-10-04依使用者確認納入GitHub發布。本輪取代先前反覆裂牆提示與60秒自動箭頭的方案。

## 最終規則

- 開場維持三行，完整操作在暫停選單；異常存檔警告保留。
- 距裂牆120px內且能量足夠，首次顯示E／長按A教學。之後只在牆旁保留小按鍵，地板與天花板附方向；停留、離開重返都不重播大字。
- 能量不足不主動提醒，實際嘗試破牆才說明不足。第一次拾取使能量達30會提醒一次，花掉再集滿不重播。
- 能量與翼能碎片取消逐次文字，保留吸收光圈、音效、HUD數值和短暫亮色回饋。減少動態時不位移。
- 受傷保留原效果、音效及生命條，取消一般受傷文字。死亡返回仍提供必要狀態通知。
- 成功存檔改為亮起兩秒存檔圖示；失敗仍明確顯示原因。
- 教學只出現一次，成功操作可直接標記學會。一般教學顯示4秒，結束後至少15秒才允許下一則；只檢查當下情境，不再排隊補播過期訊息。
- 裂牆光暈保留，減少動態時使用固定外框；不改凝視記錄、破牆距離、消耗與碰撞。
- 移除60秒自動催促。只有按「感應方向」才出現箭頭；第一道牆尚未打通時指向最近裂牆，之後沿用光點／出口查詢。手機暫停選單新增同一功能。
- 四個主題區首次進入只顯示名称，不含描述句，約2.5秒淡出且不暫停。
- 藏品與殘響的大卡片維持原規則。
- 學會項目、安靜間隔與到訪區域沿用休息燈快照保存，新冒險重設；舊快照待播教學會清空。
- 不修改敵人、傷害、魔王數值、關卡結構、冷卻、物理或鏡頭。
