# 探索版：能量與戰鬥數值調整

2026-10-08 完成本機驗證；2026-10-09 經使用者確認，納入 `feature/first-adventure-rework` 發布。原版 `main` 不變。

## 核對原有區域配置

兩組根脈橫向氣流、兩處裂鏡牆刺、8隻老鼠／7隻純史萊姆／2隻大史萊姆／4隻初始青影鳥／3隻樹妖，以及青影鳥每主題區3秒增殖、上限4隻，已在前一輪實作。本輪再次測試，不重複新增。氣流目前在安全平地，沒有新增跨坑的地形；順風跨缺口仍留待後續關卡設計。

## 本輪變更

| 項目 | 結果 |
|---|---|
| 破牆能量總量 | 110→176點，精確增加60%；破牆仍消耗30 |
| 拾取物 | 橘色拾取物46→74個，新增28個，每個2或3點；開場30個各1點不變 |
| 新增分布 | 14個位於中後段原有路線的能量點附近、6個在第二件藏品房、8個在第三件藏品房，沿藏品附近與回程擺放；沒有新增取得能力才可拾取的限制 |
| 回血顏色 | 一般翼能／回血碎片及紅熊大塊危急能量改為綠色，連同光暈、拾取框、地圖記號與HUD名稱；手机掌機操作區仍維持灰階 |
| 滿蓄力光彈 | 3傷害；普通彈維持1；三向藏品只影響普通彈 |
| 紅熊 | `BOSS_MAX_HP=36`，初始生命、重試、HUD文字／血條與試玩入口共用最大生命 |
| 召喚 | 75%／50%／20%不變，對應27／18／7.2HP；每門檻一次 |
| 水晶老鼠 | 2HP，滿蓄力一發直接歸零，不留下史萊姆；普通彈仍兩段式 |

回血量、碎片回血累積、危急回復掉落、斬擊範圍、衝刺傷害、冷卻、紅熊招式均不變。

關卡配置升為 `adventure-4`，避免舊快照還原舊獎勵列表而漏掉新增能量。沿用不相容存檔保留與新冒險覆蓋確認；需開新局體驗新分布。

## 驗證

`npm test` 全套48個測試檔通過，結束碼0；新增綠色像素驗證的瀏覽器案例另行重跑通過。`git diff --check` 通過。

- 100種子：總能量176、開場30、74個唯一拾取ID、中後段及第二／第三藏品附近6／8個新增拾取物、獎勵未嵌牆、全部新增能量與三光點／魔王入口可達。
- 真實遊戲蓄力／放開路徑：12發滿蓄力擊倒36HP紅熊；測試隔離移動與援軍擋彈，以驗證傷害，而非宣稱實際戰鬥只需12次操作。
- Canvas HUD顯示36／36，受一發後33／36且血條比例220／240；死亡重試回36。
- 27／18／7.2HP門檻前後及重複更新，各門檻只召喚一次。
- 滿蓄力一發老鼠歸零且沒有殘留，普通彈仍先變史萊姆再消失；普通三向／滿蓄力單發不混用。
- 綠色碎片與大塊回復能量實際Canvas像素確認為綠色，HUD名稱一致。
- 既有回歸仍涵蓋氣流週期與安全距離、牆刺等待位置、敵人密度、存檔、手機操作、音效及完整路線。

玩家說明與README已同步；真人的後段補給節奏與新戰鬥難度仍需試玩確認。
