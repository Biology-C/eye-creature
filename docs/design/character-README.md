## 角色結構
主體為一顆圓形白眼球、大黑瞳孔、一對後側黑色翅膀及一條後下方長尾。沒有額外軀幹、手腳或觸手。
瞳孔可轉動；眼球在轉向時保持球體比例。翅膀改為西洋龍式爬蟲質感膜翼：上臂、肘、腕與延長指骨支撐連續皮膜，後緣在指骨間形成弧形凹口。以黑色骨架線與灰色交叉排線表現皮膜，不畫羽毛或毛髮。收翼時關節折疊、指骨收攏；展翼時皮膜張開。側視遠側翼可遮擋，但必須有兩個獨立翼根。
尾根與翼根分離。尾巴粗根漸細至尖端，沒有腳掌、吸盤、箭頭、分岔或抓握器官。尾巴用於平衡、表情與弧線甩擊，不伸縮、不抓物、不踩地。

以眼球直徑 D 為單位：尾根至尾尖沿中心線的長度約 1.5D。這是首輪比例設定，後續綁定保持固定長度；彎曲與透視可以縮短投影長度，不能改變實際長度。地面陰影只用於表達懸浮高度，不是接觸點。

## 動作規格
| 圖中標籤 | 動作 | 身體／翅膀 | 尾巴 |
|---|---|---|---|
| 01 HOVER | 懸停 | 輕微上下起伏，小幅拍翼 | 懸空彎曲、緩慢擺動 |
| 02 SLOW DRIFT | 慢速漂移 | 略向前傾 | 延遲跟隨、平衡 |
| 03 FAST FLIGHT | 快速前進 | 前傾增加、加大拍翼幅度 | 向後展開，不伸長 |
| 04 BRAKE / TURN | 煞停／轉向 | 身體先減速或轉向，翅膀調姿態 | 先隨慣性擺向原方向，再收回 |
| 05 ASCEND / DESCEND | 上升／下降 | 上升強拍翼、下降減少拍幅 | 配合重心，保持離地 |
| 06 GLIDE | 滑翔 | 翼面展開，結構完整 | 自然向後延伸 |
| 07 TAIL SWEEP | 尾巴甩擊 | 身體反向預備後轉身 | A 收尾蓄力 → B 弧線甩出 → C 回復 |

A／B／C 必須是同一次連續動作。製作動畫時需追蹤尾尖弧線，不可直接在姿勢間跳接或拉長尾巴。圖中的虛線箭頭為軌跡輔助，不是第二條尾巴。速度線也是額外效果，不能替代身體部件。
本次未指定幀數、攻速、傷害或碰撞格數；不將概念關鍵姿勢直接當成可循環動畫。

## 美術與檢查結果
黑白手繪墨線、淺色紙面；不加入皇冠、披風、紅面罩或藍色門。
已視覺檢查四視圖和七類動作：大眼球、翼、單尾輪廓可區分；沒有落地踏步或吸盤／腳掌；背面不畫瞳孔；速度線獨立於翅膀。
局限：生成圖不是精密等比例製圖，尾長與翼面在不同姿勢仍有差異；結構圖的尺寸插圖也僅為示意。正式動畫前須依 1.5D 文字規格統一尾骨長度、翼根位置與眼球比例，並補驗實際遊戲尺寸下的辨識度。尚未完成使用者角色審閱或動畫驗收。

## 後續整合保留
先不決定俯視迷宮或橫向平台，也不搬移 Eye Bell Rush 程式。
玩法評估重點是持續探索、找出口，減少頻繁停下操作面板。
能力本次冒險持續保留，可跨安全屋與關卡；全新冒險才重置。收藏、替換、死亡時處理待玩法整合確認。
尾巴甩擊先確立角色動作，不決定是否取代斧頭或其傷害範圍。
