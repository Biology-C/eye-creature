# 危急回復能量與重要訊息卡片

本機探索分支改造；未推送。紅熊生命、傷害、攻擊招式和既有冷卻數值保持原值。

## 回復能量

- `src/boss-recovery.mjs` 提供掉落、拾取與繪製，接入紅熊重踏和更新事件。
- 玩家存活且HP≤2、場上無能量、遊戲時間距上次掉落嚴格大於20秒才掉落。首次以無上次掉落處理；沒有隨機判斷。
- 落點位於關閉出口門前的房間地面，離紅熊中心至少246px（既有126px重踏範圍再留120px），詛咒期間離鏡子至少120px。
- 鏡子沿用遠側邏輯，改落在遠側安全邊緣，確保紅熊位於任何合法位置時，仍有符合上述距離的能量落點。
- 拾取回復1HP，上限沿用MAX_HP；播放一次藏品拾取音效。無逾時、死亡與重試及勝利清除。
- 掉落冷卻使用遊戲時間，暫停與閱讀卡片時不流逝。此物件屬魔王戰暫態，不納入休息燈快照。

## 重要卡片

- `src/message-card.mjs` 管理DOM、排版內容、600ms壁鐘保護與輸入攔截；`styles/message-card.css` 提供深淺色和手機排版。
- 藏品取得、首次能力解鎖（隨藏品）與安全時顯示的殘響進入卡片佇列。普通提示維持現狀。
- 閱讀狀態不執行世界更新，時間、敵人、陷阱和攻擊效果停止。和既有暫停一致，清除按鍵並取消當次蓄力，不會在關閉卡片時意外發射。
- Space、Enter、手机A或點擊卡片，顯示滿600ms後才可關閉；按住鍵的重複事件與放開事件一併攔截。
- 圖示使用 `src/pickup-art.mjs` 與遊戲內同一繪圖函式。卡片寬66vw，桌面標題24px、內文18px；手機內文至少16px，短螢幕允許卡片內部垂直捲動。
- 無縮放或滑入動畫；減少動態模式同樣無動畫。殘響仍記錄在旅程與回憶，戰鬥中收集延後展示。
