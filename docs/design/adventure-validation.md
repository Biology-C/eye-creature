# 第一關改造：驗收與試玩紀錄

## 自動驗證的範圍

- 100個支路種子：敵人與必要資源數量、六支路、圖結構及實際地磚連通、獎勵不嵌在石牆、光點及出口可達。
- 凝視四方向、0.6秒門檻、遮擋；風場30/60/120 FPS不補翼能、速度上限、向下抗風；障礙階段、樹樁去重、鏡頭緩衝。
- 真實瀏覽器載入後，以相同物理更新進行無傷導航：沿路拾取30能量、凝視、破牆、風道回環、收三光點、進紅熊房。戰鬥另測30個命中及出口解鎖。另從各支路入口開始，以實際移動和連段走完六支路，取得三藏品與三殘響；不以此宣稱真人完整收集。
- 存檔／重載：破牆、風道、樹樁、殘響、半點敌人生命、大史萊姆子體、能力；反覆進燈不補血；取消覆蓋；不相容存檔保留；儲存配額失敗提示。
- 桌面1280×720與1920×1080，暫停設定可用、無頁面溢出、隱藏未實際啟用的魔法切換。
- 舊生成迷宮的模型與戰鬥回歸仍保留；舊瀏覽器案例明確使用 `?legacy=1`。新增第一關驗收使用預設入口。

执行：`BROWSER_CHANNEL=chrome node scripts/test.cjs`（PowerShell先設定 `$env:BROWSER_CHANNEL='chrome'`）。圖片在忽略的 `tests/artifacts/`，不把測試產物納入正式素材。

## 本輪實際結果

- 全套28個測試檔通過；地圖回環及區域配色修正後，新增模型與瀏覽器驗收另行重跑通過。
- 100種子檢查通過；預設種子的實際物理導航從首道裂牆、風道回環到三光點／魔王入口約102秒（隔離傷害，非真人遊玩時間）。
- 六支路從各入口開始實際移動、連段清障，取得三藏品與三殘響。存檔與錯誤處理驗收通過。
- 檢視桌面起點、風道、根脈地標、殘響與暫停畫面；`git diff --check` 無錯誤。

## 尚未完成、不得宣稱通過

- 至少五位首次接觸玩家，其中一位六歲玩家。
- 4/5玩家不需口頭指導完成首次凝視、破牆與回環。
- 首次探索與戰鬥是否落在10～15分鐘。
- 主觀操作疲勞、敵人密度、鏡頭舒適度與音效感受。
- 手機介面及真實手機多指測試：使用者已要求暫緩，不是本輪交付条件。

無傷導航只證明可達性，不代表正常生存難度或通關時間；測試中直接定位的存檔／戰鬥案例也不視為完整真人通關。
